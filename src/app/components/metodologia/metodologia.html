Proceso de desarrollo del sistema AgroSoft

Metodología Ágil

El desarrollo de AgroSoft se ha llevado a cabo utilizando metodologías ágiles, específicamente adaptando principios de Scrum y Kanban para garantizar un desarrollo iterativo e incremental que responda a las necesidades reales del cliente.

Fases del Proyecto

1

Análisis y Requerimientos

Se realizó un análisis exhaustivo de las necesidades de Estancia del 10, identificando los problemas principales: falta de control unificado del rodeo, dificultades en la organización de vacunaciones, y ausencia de reportes confiables.

2

Diseño y Arquitectura

Se diseñó una arquitectura modular basada en Angular, utilizando servicios para la gestión de datos y componentes reutilizables. Se implementó almacenamiento local (localStorage) para la persistencia de datos sin necesidad de backend inicial.

3

Desarrollo Iterativo

El desarrollo se realizó en sprints cortos, priorizando funcionalidades críticas: registro de animales, gestión de ventas, control sanitario y generación de reportes. Cada iteración incluía pruebas y retroalimentación.

4

Implementación y Pruebas

Se realizaron pruebas exhaustivas de cada módulo, validando la integridad de los datos, la usabilidad de la interfaz y la correcta persistencia en localStorage. Se corrigieron errores y se optimizó el rendimiento.

Características del Sistema

📋

Registro de Animales

Alta completa de ganado con información detallada: caravana, raza, peso, estado sanitario.

💰

Gestión de Ventas

Registro de ventas con historial de comercialización por animal o lote.

💉

Control Sanitario

Seguimiento de vacunaciones, tratamientos y controles veterinarios.

📊

Reportes y Estadísticas

Análisis de stock, ventas mensuales y comparativos de períodos.
